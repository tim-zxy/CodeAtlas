# ADR 004 Automatic Facts and Manual Knowledge

Status: Accepted

Decision: Source fingerprints, code facts, contracts, `ExecutionGraph`, `RuntimeFlow`, document structure, and impacts update automatically. Semantic claims, capabilities, business flows, architecture knowledge, and wiki publication update through an explicit knowledge command.

Consequences: code stays fresh during development without narrative churn; affected knowledge remains usable with warnings; automation beyond this boundary needs a future approved policy.
