# Codex Compatibility Handoff

This filename is retained for compatibility with Codex-oriented automation and earlier references. The authoritative, agent-neutral entry is `ENGINEERING_HANDOFF.md`.

Before changing code, follow the repository root `AGENTS.md` and read, in order:

1. `ENGINEERING_HANDOFF.md`
2. `CURRENT_STATUS.md`
3. `DESIGN_AUTHORITY.md`
4. `IMPLEMENTATION_PROTOCOL.md`
5. The active phase sections of `WORK_BREAKDOWN.md` and `PHASE_ACCEPTANCE.md`
6. Relevant ADRs and specs

Codex has no special authority beyond another Engineering Agent. All FROZEN, EVOLVABLE, DEFERRED, phase, evidence, security, and acceptance rules apply identically.
