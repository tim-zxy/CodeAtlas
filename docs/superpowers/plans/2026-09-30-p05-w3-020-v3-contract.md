# Native v3 Contract Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver strict cross-language retained-analysis/request validation for P05-W3-020-A, without advertising or implementing REFRESH.

**Architecture:** Reuse existing IR/Native schemas and byte-budget rules. Add isolated, side-effect-free TypeScript/Rust validators plus one shared raw-byte corpus; later reviewed packets connect producer, lifecycle and atomic Store.

**Tech Stack:** Node 24, TypeScript/Zod, Rust/serde_json/sha2, existing Node test runner and Cargo. No added dependency.

**Spec:** [P05-W3-020-A detailed design](../specs/2026-09-30-p05-w3-020-v3-contract-design.md); accepted ADR-016 and parent DCP. User approved this plan and native execution on 2026-09-30. All four tasks are locally implemented; one final independent review identified contract defects, repaired via shared RED→GREEN vectors. Integration remains open.

## Global Constraints

- Keep strict v1/v2, IR v1, ProviderSnapshot v1 and existing producer advertisement unchanged.
- Ceilings: aggregate stdin and individual lines 1,000,000 bytes; stdout 10,000,000 bytes; output events 10,000; stderr 1,000,000 bytes. These are inherited protocol caps, not performance targets.
- No SQL, DB handle, process spawn/dispatch, raw source/AST persistence, new language/framework or semantic knowledge in this packet.
- User confirmed native execution after written-plan review; executing-plans implements inline with one final fresh-context branch review.
- Files/tests below are packet deliverables; fresh evidence belongs in CURRENT_STATUS, not inferred from checkboxes. Follow AGENTS required reading and isolate edits on the existing design worktree before execution.

## Review Focus

- Non-ASCII paths/identifiers/source text: TS/Rust canonical ordering, compilation-unit byte-length identity and UTF-8 spans agree; Task 1/3 pins independent vectors.
- Failed Apply followed by an empty latest delta: baseline→target disagreement rejects, not CURRENT; Task 2/3 covers it.
- Shared synthetic node across files: identical SHARED support allowed, conflicting digest or FILE owner rejected; Task 1 covers it.
- Resource-bound input: multibyte line/aggregate limits count bytes including LF; Task 2/3 tests exact cap and cap+1.
- Valid prefix followed by junk/truncation: neither decoder returns a partial baseline; Task 2/3 tests EOF/post-terminal and corruption.
