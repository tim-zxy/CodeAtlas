# P05-W3-001 Java Symbol Extraction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Emit deterministic, source-verified Java symbol Provider Facts, diagnostics, and coverage through Native IPC v1 without activating a graph.

**Architecture:** A Rust `LanguageAnalyzer` boundary isolates Java Tree-sitter traversal from the Native coordinator. The coordinator validates `ANALYZE`, securely reads the request's SourceFiles below `repository.rootPath`, runs a bounded parser pool, and emits a checksum-protected JSONL stream. TypeScript supplies the one validated worker setting through an internal process argument; cross-language Fixtures exercise the existing byte-stream client.

**Tech Stack:** Rust 1.98.1, Tree-sitter Rust/Java, `serde_json`, SHA-256, capability-relative file access, Node 24 TypeScript, Zod Native IPC/IR schemas, Node and Cargo test runners, Evaluation manifest v1.

**Spec:** [Approved P05-W3-001 design](../specs/2026-09-25-p05-w3-001-java-symbols-design.md)

## Global Constraints

- Work on `codex/p05-w3-001-java-symbols`; preserve user changes and keep Phase 0.5 active. P05-W2-002 is integrated by PR #9 at `813fcbe`.
- Preserve strict Native IPC v1, Canonical IR v1, published SQLite migrations, and the one-request `DESCRIBE` behavior. Rust writes no Canonical SQLite and emits no framework semantics.
- The only repository root is `ANALYZE.payload.repository.rootPath`; SourceFile paths are canonical repository-relative paths. Reject path/symlink/reparse escapes and fingerprint mismatch before emitting source facts.
- The only worker setting is `EffectiveConfig.indexing.nativeAnalyzer.parseWorkers` (`AUTO` or positive safe integer). Carry the validated effective count via a private process argument, never a new IPC field or independent Rust user knob.
- Bound pending files, in-flight parses, completed results, JSONL output, event count, and process memory. A failed/incomplete stream never becomes applicable; a fully validated `PARTIAL` syntax result may.
- Keep imports/calls/inheritance/references in P05-W3-002; full outcome statistics in P05-W3-003; REFRESH, normalization, SQLite activation, full Worker Consistency, and cold/1-/5-/50-file baselines in their assigned later tasks.

- Use RED→GREEN tests, commit independently reviewable tasks, and update `CURRENT_STATUS.md` and traceability only with fresh reproducible evidence.

## Review Focus

These five conditions need explicit tests in the owning task:

1. An ancestor becomes a symlink/junction after scanning: Task 2 rejects the read, including the Windows reparse case, without leaking outside bytes.
2. The file changes with the same byte length: Task 2 reports `SOURCE_CHANGED`, not a stale successful symbol list.
3. Two methods have the same name but different source-spelled parameter signatures: Task 1 gives distinct stable Provider Fact IDs and exact ranges.
4. A later worker finishes first while the stdout consumer is slow: Task 4 emits the same ordered facts without unbounded completed results.
5. A stream ends after `ANALYSIS_STARTED` or has a wrong checksum: Task 5 proves the TypeScript client exposes no applicable partial events.

**Interfaces:** Produce `read_verified_source(root: &Path, relative_path: &str, expected_fingerprint: &str, max_bytes: usize) -> Result<Vec<u8>, SourceAccessError>`. - [ ] **Step 3: Implement capability-relative reading.** Pin `cap-std = "=4.0.3"` if compatible with Rust 1.98.1; otherwise stop with compiler evidence for a reviewed dependency adjustment. Reuse Task 1's `sha2`. Create one capability `Dir` from the validated absolute root, inspect each component with no-follow metadata, reject Windows reparse attributes, and open through that directory only; the [cap-std `Dir` API](https://docs.rs/cap-std/4.0.3/cap_std/fs/struct.Dir.html) provides relative opening and no-follow metadata. Define private `validate_relative_components(&str) -> Result<PathBuf, SourceAccessError>`, `reject_linked_components(&Dir, &Path) -> Result<(), SourceAccessError>`, `read_bounded(&mut cap_std::fs::File, usize) -> Result<Vec<u8>, SourceAccessError>`, and `verify_unchanged_and_hash(&Dir, &Path, &cap_std::fs::File, &[u8], &str) -> Result<(), SourceAccessError>`. Recheck identities/metadata around the bounded read, calculate raw-byte SHA-256 from the opened handle, compare the supplied fingerprint, and return no bytes on any failure. This is a process-local security check, not a change to opaque IR fingerprint validation.

```rust
pub fn read_verified_source(root: &Path, relative_path: &str, expected_fingerprint: &str, max_bytes: usize) -> Result<Vec<u8>, SourceAccessError> {
    let directory = cap_std::fs::Dir::open_ambient_dir(root, cap_std::ambient_authority()).map_err(SourceAccessError::Io)?;
    let path = validate_relative_components(relative_path)?;
    reject_linked_components(&directory, &path)?;
    let mut file = directory.open(&path).map_err(SourceAccessError::Io)?;
    let bytes = read_bounded(&mut file, max_bytes)?;
    verify_unchanged_and_hash(&directory, &path, &file, &bytes, expected_fingerprint)?;
    Ok(bytes)
}
```

- [ ] **Step 3: Implement strict decoding and emission.** Reuse the DESCRIBE framing limits and trustworthy request-ID rule; dispatch on type only after envelope validation. Decode `ANALYZE` fields with deny-unknown-fields semantics matching `native-ipc.ts`, validate source ownership and unique IDs, enforce deadline/resource budgets, and map errors to closed v1 codes.
```rust
fn emit(&mut self, event_type: &str, payload: serde_json::Value) -> io::Result<()> {
    let line = serde_json::to_vec(&json!({"protocolVersion": 1, "requestId": self.request_id, "sequence": self.sequence, "type": event_type, "payload": payload})).map_err(io::Error::other)?;
    self.check_limits(line.len() + 1)?;
    self.output.write_all(&line)?;
    self.output.write_all(b"\n")?;
    if event_type != "ANALYSIS_COMPLETED" && event_type != "ANALYSIS_FAILED" {
        self.checksum.update(&line);
        self.checksum.update(b"\n");
    }
    self.sequence += 1;
    Ok(())
}
```
