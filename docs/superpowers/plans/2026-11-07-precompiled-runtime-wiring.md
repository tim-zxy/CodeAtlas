## Global Constraints

- No actual Windows account query, protected install, ACL change, persistent access, user migration or R9.
- Keep old rejection rules and path compatibility; no missing-DLL/unknown-trust fallback.
- Reuse existing6656-byte DLL SHA4ee3e48cfa2f6c4d883a983a2f7b5739ecf7b01d515c94cecbed9f87e3bb7147; do not rebuild.
- Same copied bytes are hashed then loaded; no DLL payload reread after verification.
- Shared explicit controls, close/EOF, cancellation invalidation, epoch and UNKNOWN semantics stay.
- Physical package is owned test data, not a trusted production install or granted Principal.
- One integrator; file-isolated streams; one final source sync, no duplicate CI dispatch.

## Review Focus

- Directory/hash claims cannot create grants; actual OS KnownFolder/protection remain mandatory.
- No external links, unknown files, path traversal/case aliases or hidden compiler fallback.
- Workspace aliases must resolve to canonical single module identities, not duplicate Storage classes.
- Cancel/metadata drift/abnormal exit cannot mint or revive handles; no legacy temp cleanup in DLL mode.
- Candidate package metadata and source head do not substitute actual closed-content hashes or production qualification.
