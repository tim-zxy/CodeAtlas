## Evidence and intent

The user wants Phase1 development to continue locally while preserving all gates and consolidating CI at a later reviewed integration point. C1 binds exact preparation identities but cannot authenticate live state. C2 executed exactly4 owned Node helpers, each once: held-ready retained-handle final peak was available; already-closed and injected failure stayed unavailable; cancellation stayed CANCELLED even with a final peak. All targets and collector closed, both acquired handles released. These observations support further design of external acquisition; they do not qualify actual Native, fast failure, production transparency, restart or profile values.

C1's real file symlink refusal gate remains OPEN because Windows denied creation (EPERM). Junction, hardlink and deterministic replacement checks passed. A capable, authorized environment must supply that missing real-file test; no system privilege change or waived gate is proposed. Previous full Java/mixed candidate, Canonical Syntax/support/CAS/Store, actual context/resource/restart gates remain OPEN. Historical Native timeout remains UNKNOWN.
