# Owned published BusinessFlow trace

Existing AGENT_API and knowledge-and-consumption section9 define explicit BUSINESS traces of published knowledge, distinct from Code/ExecutionGraph/RuntimeFlow. BusinessFlowContentSchema already defines unique stepKey, action, supportRefs and nextStepKeys, with local targets enforced. This batch follows only those existing edges inside one exact selected published revision; no new identity, inferred temporal order, cross-flow linkage, graph schema or authority.

Private request is exact {kind:BUSINESS,workspaceId,repositoryIds,knowledgeRef:{itemId,revisionId},startStepKey,direction:FORWARD|BACKWARD,maxDepth,maxSteps,maxEdges,maxResultBytes}. All budgets are explicit; maxDepth may be zero, others positive safe integers. No token estimator/default is chosen. The public tool/token/ResultMeta adapter stays open. A fixed owned KnowledgeQuery port requests only that exact revision, under a fixed workspace. Reuse the current published selection/IR/scope/provenance/coverage validation from Wiki without executing the profile or renderer. Preserve Wiki behavior and its original private errors.

Knowledge performs deterministic breadth-first traversal with stable key tie order, visits each step once, retains original edge direction during backward traversal, and returns only original actions/support references. maxDepth/steps/edges stop expansion with explicit frontier and truncated state; cycles do not loop. Whole response including provenance/coverage/limitations/frontier must fit maxResultBytes or fail with typed budget error rather than a false empty response. Original cooperative control bounds graph/data processing.

Return kind BUSINESS, exact Knowledge item/revision reference, title/goal, bounded steps/edges/frontier, source freshness/currency, original coverage, provenance, participants/runtime references and limitations. AFFECTED/STALE is returned with warnings, not hidden or relabeled fresh. Never fetch live facts, execute a flow, read raw Source/Claim bodies, invoke update/model or infer runtime equivalence. Missing/denied/malformed/pending/foreign/other-kind input refuses; zero-hit success is not a substitute for an unavailable flow.

Use explicit synthetic published fixtures for positive graph cases and actual self-owned Store reading for no-write/type-boundary integration. Output remains NOT_EVALUABLE / productionQuery NOT_AUTHORIZED. Public API/MCP, production query, token admission and real quality acceptance are not delivered here. No user DB, permissions, production publish, Native/R9 or new dependency. Disable private module to roll back; no canonical history is changed.

Historical selection retains the exact selected revision. Current head ID and isCurrentHead are separate output metadata; a differing current head always adds HISTORICAL_PUBLISHED_REVISION even if the query supplies no warnings. Stored freshness/currency are not rewritten, and no live Source observation is inferred.
