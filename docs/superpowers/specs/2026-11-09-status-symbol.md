## Compatibility and rollout
No code or knowledge Canonical enum changed. New nullable/not-applicable fields exist only in this new symbol public contract, explicitly versioned. Status only covers selected current metadata; symbol only stored code and exact active revision, no position lookup or runtime quality claim. Rollback disables two additive routes, retains all history. Original P1-17/18 and phase4/21,A6 NOT_QUALIFIED,E02 PROPOSED stay open.

Implementation lifecycle refinement within the same approved boundary: App emits QUERY_CLEANUP_FAILED/cleanupState UNKNOWN if its owned handle cannot be closed. Symbol source-work is registered before invoking external opener; its session abort signal is merged with caller control, close invalidates then joins those work promises, and any cleanup loss permanently poisons the context. close's retained Promise is internally observed to avoid unhandled rejection but still rejects to its owner; SDK awaits all returned invalidations and reports UNKNOWN. Cancellation or earlier close never erase the cleanup fact. No automatic re-open/retry. Caller-owned shared status stores remain outside session resource ownership; status reads do not close the external store.
