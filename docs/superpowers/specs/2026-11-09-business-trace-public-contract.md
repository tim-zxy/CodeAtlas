# BUSINESS trace public contract v1 (owned-data delivery)

Approval: user explicitly approved refining and implementing the limited BUSINESS public contract against self-owned data. Other trace kinds remain unavailable; no MCP SDK, production data access, source scan/model, W011 installation or production publication. This is the first version of the Agent contract, not a change to Canonical IDs, BusinessFlow steps or AUTO/MANUAL boundaries (ADR004/007/009/020 remain controlling).

## Wire contract

Arguments are a strict discriminated v1 union. BUSINESS is exactly {version:1,kind:BUSINESS,startRef:{kind:KNOWLEDGE_ITEM,id,revisionId},startStepKey,direction:FORWARD|BACKWARD,budget:{maxDepth,maxSteps,maxEdges,maxOutputBytes,maxTokens}}. IDs reuse existing IR, revision is mandatory and exact, stepKey stays revision-local. maxDepth is nonnegative; other limits are positive safe integers, no defaults. Known unavailable selector forms are exactly {version:1,kind:CODE|EXECUTION|RUNTIME}, returning FEATURE_UNAVAILABLE without querying; actual future argument schemas for these kinds are not invented. Unknown fields/kinds/versions refuse. Public descriptor declares only BUSINESS support, not completion of four kinds or six tools.

Success is exactly {data,meta}. data includes BUSINESS/startRef/startStepKey/direction, title/goal, selected steps/edges, currentHeadRevisionId/isCurrentHead, participants/runtimeFlowRefs, original flow supportRefs, provenance, limitations, quality NOT_EVALUABLE and productionQuery NOT_AUTHORIZED. meta is exactly {basisRefs,sourceFreshness,compilationCurrency,coverage,warnings,truncation}; basisRefs reuse the existing RepoBasis|DocumentBasis|WorkspaceBasis strict union, deduplicated by basisKey from the flow and returned steps. Coverage and stored freshness/currency are preserved, never guessed. truncation is exactly {truncated,reasons,frontier}; frontier preserves local edge/depth/reason and the pinned revision is in data.startRef. No fabricated continuation token. Safe warning codes only; unknown port text becomes UNCLASSIFIED_WARNING, not raw diagnostic text. All owned-mode successes include OWNED_TEST_ONLY and NO_PRODUCTION_AUTHORITY.

Failure is exactly {error:{code,message}}, with fixed safe messages and no paths, stack, raw diagnostics, existence metadata or partial data. Codes: INVALID_INPUT, FEATURE_UNAVAILABLE, CONTEXT_UNAVAILABLE, PERMISSION_DENIED, TOKEN_COUNTER_UNAVAILABLE, BUDGET_EXCEEDED, CANCELLED, DEADLINE, NOT_FOUND, DATA_INVALID, PROVIDER_UNAVAILABLE. Missing/denied/corrupt flow is not successful empty data.

## Server ownership and budgets

createOwnedBusinessTraceSession fixes workspaceId, repositoryIds, maximum budgets, a synchronous authorization callback, exact published query and optional tokenCounter at construction. It mints one opaque process-local context handle; execute(input,context,control) accepts only that actual session handle. JSON lookalikes, handles from another session or after close refuse. No identity/permission/capability/count can be supplied in arguments. The owned authorization callback is a test assertion boundary, not a production Principal/Operation issuer or proof of human approval. It checks the full frozen selection/field manifest before query and again before result delivery. Only QUERY is named; Source, update, publication and model methods do not exist on this port.

The optional counter is a fixed server-side local port {kind:EXACT_LOCAL_COUNTER,policyRef,measure(serializedResponse,control)} returning exactly {policyRef,contentDigest,outputTokens}. contentDigest binds SHA256 of the canonical complete {data,meta} JSON bytes; policyRef must match the captured policy, tokens must be a positive safe integer. No caller-provided counts, ratio/character guesses, async/estimated fallback or model request. Null/unsupported counter fails before query; malformed/mismatched/failed measurement refuses output. Tests inject explicit fixture-only counters; this proves enforcement mechanics, not a production tokenizer. No reviewed production counter is installed or enabled by this batch.

Effective per-call limits are the minimum of caller and fixed server ceilings. Existing request-control traversal/depth/cancellation/deadline are preserved. maxOutputBytes counts the complete canonical UTF8 {data,meta}, including all support, basis, coverage, warnings and frontier; maxTokens applies to exactly that same serialization under the fixed policy. Metadata that cannot fit fails instead of being dropped. Transport framing/buffer bounds belong to later MCP composition and are not claimed here. Callback throws never leak their message; a Promise returned from a synchronous authority/counter invalidates the session before observation; normal native Promise rejections are observed without unhandled rejection. Exotic host Promise species/constructors or thenables violate this synchronous port contract: reject with the same safe error and keep the session closed, without mutating the host object or global rejection policy. Such host-started work cannot be certified settled; no unhandled-rejection or process-lifecycle guarantee is made for an unobservable exotic Promise. Declared async callbacks are rejected without invocation.

## Implementation and compatibility

Agent API uses existing Zod4.6.1 plus IR/Application workspace dependencies permitted by architecture. Additive public module exports only; Runtime does not acquire an Agent API dependency. Reuse the actual owned BusinessFlow tracer; add its already-authorized flow support metadata to avoid losing provenance. No new database schema, public MCP/stdin route or production query is registered. Rollback disables session creation/export consumers and retains canonical histories; no data migration/down path. Public schema, permission/counter refusal and exact response fixture tests precede implementation; unchanged private Wiki/trace behavior is regression-tested. Original P1-17/18 and quality/Native gates remain OPEN.
